# mood.fm

A mood-based song recommendation website that helps you find a soundtrack for how you feel.

## Features

- Choose from Sunny, Soft, Focus, or Electric moods
- Get a curated set of song recommendations for each mood
- Use the random mood button for an unexpected pick
- Preview a selected track in the built-in now-playing bar
- Responsive layout for desktop and mobile screens

## Run locally

From the repository root, start a local server:

```bash
python3 -m http.server 4173 --directory "1st repo"
```

Then open [http://localhost:4173](http://localhost:4173) in your browser.

## Project files

- `1st repo/index.html` contains the page structure
- `1st repo/style.css` contains the responsive visual design
- `1st repo/app.js` contains mood selection and recommendation interactions
